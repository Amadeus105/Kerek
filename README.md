# Керек

Поиск товаров из Китая с ценой в тенге. Вводишь «мужские штаны», выбираешь размер и бюджет, получаешь карточки с ценой в ₸, названием на русском и ссылкой на магазин.

## Как это работает

```
запрос -> источник товаров -> перевод названий -> цена в ₸ -> фильтры -> карточки
```

| Файл | Что делает |
|---|---|
| `app/main.py` | страница `/`, JSON `/api/search`, `/health` |
| `app/search.py` | склеивает весь поиск в одну цепочку |
| `app/sources/mock.py` | демо-товары, пока нет ключей |
| `app/sources/aliexpress.py` | AliExpress Affiliate API (ещё не проверен на живых ключах) |
| `app/rates.py` | курс Нацбанка РК, кэш на 6 часов, запасной курс при сбое |
| `app/translate.py` | перевод на русский через DeepL, кэш в памяти |

## Запуск локально

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
copy .env.example .env
uvicorn app.main:app --reload
```

Открыть http://127.0.0.1:8000

Без ключей сайт работает на демо-товарах. Курс берётся живой с nationalbank.kz.

## Деплой на Render

1. Залить проект на GitHub.
2. На render.com: New → Blueprint → выбрать репозиторий. Render прочитает `render.yaml`.
3. Ключи вписать в Environment у сервиса.

На бесплатном тарифе сервис засыпает через 15 минут без посетителей, и первая загрузка после этого идёт около минуты.
